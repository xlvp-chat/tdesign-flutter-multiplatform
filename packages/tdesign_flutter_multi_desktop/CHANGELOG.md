# Changelog

## 0.1.0

首个稳定版本。通过仓库 tag `desktop-v0.1.0` 交付，不发布到 pub.dev。需单独依赖 `tdesign_flutter_multi_core` 0.1.0。

- Desktop / Web 组件：Button、Input、Select、Form、Date/Time 及区间、Cascader、Tree、TreeSelect、Upload、Table、Menu、Tabs、Dialog 等
- 颜色与圆角从 `TDesignTokenScope` 读取；本包不 re-export Core

不包含：树懒加载与虚拟滚动、Upload 真实 HTTP 与系统拖拽、像素级 Visual Diff、Web A11y 专项。
